## About the Project
This project is based on open-source software (Git) and understanding how it works in a Linux environment. It also includes some basic shell scripts.

## Scripts Included

1. script1.sh  
   This script displays basic system information like user, kernel version, uptime, and OS details.

2. script2.sh  
   This script checks whether Git is installed and shows its version and a short description.

3. script3.sh  
   This script checks disk usage and permissions of important directories.

4. script4.sh  
   This script reads a log file and counts how many times a keyword appears.

5. script5.sh  
   This script generates a simple open source manifesto based on user input.

## How to Run Scripts

Step 1: Give permission  
chmod +x script1.sh  

Step 2: Run script  
./script1.sh  


## Requirements
- Ubuntu (WSL)
- Git installed
